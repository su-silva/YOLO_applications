##  Descripción del repositorio
Este repositorio fue creado como parte de la clase de **Deep Learning aplicado a Visión por Computadora**.  

Se fundamenta en el repositorio oficial [ultralytics/notebooks](https://github.com/ultralytics/notebooks), el cual ofrece tutoriales de **YOLO** en entornos como **Google Colab, Kaggle y SageMaker**, abarcando tareas de **entrenamiento, inferencia, exportación y aplicaciones de visión por computadora**.

---

##  Notebook principal
- **train-ultralytics-yolo-on-homeobjects-dataset.ipynb**  
  Implementación práctica de entrenamiento de YOLO utilizando el dataset **HomeObjects-3K**.
